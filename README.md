# ТигрБанк
## Что моделирует программа
Программа моделирует банковскую систему "ТигрБанк"

## Используйте единый code style

При написании программы использовался camelCase.

## Добавьте модульное теcтирование.

Модульные тесты покрывают основные сервисы и располагаются в директории: src/test/java/Bank/Tests

## Соблюдайте принципы SOLID

В программе соблюдены принципы SOLID. Классы из слоя domain отвечают только за хранение базовых состояний и основную логику сущностей. Из слоя repository только за доступ к данным и их хранение. Классы из слоя service только за бизнес-логику приложения.

Классы открыты для расширения, но закрыты для модификации. Например в классе DataTransferService при добавлении новых типов файлов не придётся переписывать уже существующие методы, а потребуется только создать новый классы, реализующий необходимый интерфейс.

В метод exportAll и importAll класса DataTransferService можно передать любой класс реализующий интерфейсы Exporter и Importer.

Интерфейсы Exporter и Importer разделены и не имеют лишних методов.

Модули верхнего уровня не зависят от модулей нижнего уровня, в классах сервисов используется внедрение зависимостей через конструктор.

## Укажите ситуации, при которых появятся проблемы добавления нового функционала или расширении бизнес-логики

Проблемы могут возникнуть в случае, если заказчик решит расширить уже существующие классы слоя domain, т.к это повлечёт за собой изменение уже существующих сервисов, например импорта и экспорта файлов.

Так же могут появиться сложности если потребуется внести дополнительные методы в интерфейсы Importer и Exporter, т.к тогда придётся редактировать уже готовые реализации.

## Приведите аргументы, почему введенные абстракции улучшили качество дизайна

При необходимости добавить поддержку новых типов файлов для экспорта и импорта могли бы возникнуть проблемы, но благодаря использованию поведенческого паттерна "Стратегия" её легко избежать.

## Реализуйте работу с данными из файлов

Благодаря использованию DI-контейнера, при тестировании нет необходимости создавать реальные объекты для хранения данных.

Работа с данными из файлов реализована в классах пакета Bank.service.Files. И в классе DataTransferService.
